V2.0.1 STEP 8 FIX — RECYCLE BIN

The active Recycle Bin is now Supabase-only. Legacy localStorage recycle helpers are inert compatibility shims and no longer form a second active data store. Legacy local recycle records are migrated once into the Supabase recycle_bin table when an admin session initializes, then the old local key is removed only after successful migration. Delete, recover, and permanent-delete UI actions use the online Recycle Bin.
