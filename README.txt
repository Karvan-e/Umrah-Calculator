KARVAN E ASAL — UMRAH MANAGER V4

Mobile-first PWA styled in the Karvan e Asal navy/gold visual system.

Visa correction implemented from the supplied tariff:
- 05–49 pax: SAR 615 per adult
- 04 pax: SAR 665 per adult
- 03 pax: SAR 690 per adult
- 02 pax: SAR 715 per adult
- 01 pax: SAR 765 per adult
- Infant: SAR 475

The adult visa price is automatically selected from total non-infant group size.
Visa Management is intentionally simple: open Visa Management, tap Edit, change the five adult prices / child / infant prices, then Save Prices.

Also includes hotel add/edit, room rates, hotel distance, four stays, passenger cost separation, flight itinerary fields, transport, extras, saved quotations, PKR/SAR rate and invoice preview.

Live flight schedule/airline lookup and live FX require an external API/backend; this version does not fabricate live data.
